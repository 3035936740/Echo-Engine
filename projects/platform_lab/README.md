# 平台动作练习室

用编辑器打开project.echo，F5试玩。包含梯子、水域、传送带、弹簧、落下平台及升降平台；墙跳和冲刺已启用。位于逻辑坐标(512,544)的NPC乘坐(480,576)的升降平台，NPC模板可修改「随平台移动」「平台挤压时死亡」。

从「作品 → 平台动作 / 机关预设」修改平台路线；从「对象与模板」修改角色。Ctrl+S保存工程，模板修改后F5重新试玩并开始新历史。

按键采用项目设置；默认A/D移动、Space跳跃、W上爬、X冲刺、R快速回溯、T轨迹回溯。编辑器调试BGM默认静音，SE保留。

scripts/mobility.lua与object_movement.lua为高级例子，默认不在启动列表中；代次与跨帧数据须放engine.state。一般操作无需Lua。

这是生成的可编辑示例，原有object_lab不作覆盖。完整菜单/玩家存档、统一动态体、实体側推/多节点等仍在引擎待建范围。
