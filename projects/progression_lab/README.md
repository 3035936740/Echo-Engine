# 物品与任务练习室

用编辑器打开 [project.echo](project.echo)，F5试玩。保留平台、动画、弹幕、条件选项及两地图示例，新增无需Lua的「接委托 → 取得钥匙 → 交付 → 完成」指令链。

1. 从出生点向右，到逻辑坐标(360,588)的委托人，按E对话接任务。
2. 乘坐(480,576)的升降平台，在上方(536,336)接触发光事件取得「回声钥匙」。
3. 回到委托人按E交付。钥匙数量减少，任务完成；再次对话会提示已经完成。
4. 按T退回取得或交付之前，再松开继续：物品、任务、对话和独立开关一起恢复。R按项目快速回溯规则恢复世界，玩家走新直线。

制作入口：「作品 → 游戏数据库」查看物品与任务；地图双击委托人/拾取标记，修改原生表单指令。名称可以改，稳定ID不变。数据库定义应用会重新开始历史，Ctrl+S保存工程。数量和任务在两地图间保留；F5重开恢复新游戏初始值。

默认A/D移动、Space跳跃、W爬梯、X冲刺、E互动/继续、R快速回溯、T轨迹回溯。可从键位设置修改。调试BGM默认静音，SE保留；角色保留原图像素并整数放大。

高级用例见 [scripts/progression.lua](scripts/progression.lua)，默认不在启动脚本列表中。常规任务不需要Lua；高级跨帧数据仍放C++快照。更多限制与结果码见 [物品与任务说明](../../docs/INVENTORY_QUESTS.md)。

本例的任务只有单目标进度；完整背包菜单、物品使用效果、多目标依赖、奖励事务和玩家存档仍待建设。本工程为独立新示例，不覆盖platform_lab/object_lab。
