# Echo Engine 制作练习室
用 bin/EchoEngine.exe 的“打开”选择此目录的 project.echo，或：
```powershell
./bin/EchoEngine.exe --project ./projects/object_lab --editor
```
F5 试玩；A/D 移动，空格跳跃，E 对话／交互，T 撤回，R 直线撞击。试玩参数、资源和内容都属于本工程。

- 玩家为可部署模板，初始 5 HP。巡逻与追击敌人使用状态动画；追击实例单独覆盖速度为 50。
- 收集宝石改变“已收集宝石”，回溯恢复收集与变量。拾取物保留墓碑，重进地图不会再次给予奖励。
- NPC 与门挂接命名地图事件。E 与门交互进入黎明地图，返回区域回到练习室。
- 组合炮台的对象行为是待机，实际弹幕来自“组合炮台”发射器，按环形→锁定扇形波次循环。在“弹幕与波次”修改预设、运动、种子、预警和满池策略。
- 动画库可切分和修改时长、锚点、判定框。跑步帧增加“跑步标记计数”；回溯后仍由恢复的播放游标触发。
- 资源目录使用稳定 ID。改名／移动请在“资源管理”中操作，避免在文件管理器断开引用。
- Ctrl+S 保存；修改定义后 F5 开启新试玩历史。浅／深主题覆盖这些制作窗口。
- 可公开或认证加密导出；出口是原生 exe。这个示例没有完整标题菜单、玩家存档或结局系统，这些仍在建设。

此工程由 tools/create_examples.cpp 生成，构建后 echo_example_builder 可以从 echo_of_kino 资源创建新的练习工程，拒绝覆盖已有目标。生成器校验资源与引用，并执行完整六秒最远历史恢复后继续。16_example_project 额外创建真实窗口，导出两种包并启动验证。

区域练习：在地图部署事件，应用「进入计数」「离开计数」或「接触计数」预设，把变量指令指向新的命名变量。关闭实体碰撞即可做传感区域；在「移动本事件」选择阻挡/滑动。用试玩调试器检查变量、待触发和阻挡状态，再T/R退到最远继续。打开「碰撞分类」可试验玩家免疫弹幕预设；操作见 [碰撞分类](../../docs/COLLISION_RULES.md)。

判定与显示练习：打开「判定 / 低速 / 采样」，应用小圆判定＋Shift低速预设，修改判定半径、伤害类别和启用条件；保存后试玩，最远T/R恢复后继续移动，观察低速切换与判定显示。多区域可以复制后分别移动或选择胶囊、椭圆、矩形及凸多边形。

打开「帧率与同步」选择30/60/90/120/144 FPS、无限制或自定义上限；它只改变绘制机会，跳跃和六秒回溯不随FPS加速。开启VSync还受显示器/驱动限制。贴图过滤、放大和AA可分别选择，默认像素模式；SSAA会增加GPU成本。操作与算法边界见 [判定、低速与显示设置](../../docs/FOCUS_HIT_RENDERING.md)。

控制权练习：在事件编辑器新建条件为开关1开启的并行页，插入「玩家控制权：锁定动作」→「等待1秒」→「关闭开关1」。试玩调试器开启开关1，观察所有者/输入许可；期间长按空格，结束后需松开再按。两个并行事件的限制独立释放，T恢复历史所有者。完整规则见 ../../docs/PLAYER_CONTROL.md。

目标练习：打开「弹幕与波次」，选择「组合炮台」发射器，点「瞄准目标与阵营…」。可在命名下拉选择NPC或敌人，也可选「最近的地图对象」并指定/排除阵营；环形固定方向波忽略目标，锁定扇形波采用新目标。设置不会让对象自动承受弹幕伤害。观察目标十字、缺失计数和预警；保存后F5重启，最远T/R恢复再继续。目标丢失规则与LuaSTG参考见 [弹幕制作](../../docs/BARRAGE.md)。

部署练习：选中「组合炮台」发射器，点「在地图上定位 / 拖动…」，左键在画布放置；它仍跟随原来的炮台对象，保存的是新偏移。再抓住方框拖动，Ctrl+Z/Y对整次拖动撤销/重做；双击重开表单。世界原点与挂接原点都可练习。切图清空当前作者撤销；F5开启最新定义的试玩历史。

高级脚本练习：在NPC地图事件插入「执行 Lua 脚本（高级）」；用engine.get_variable/set_variable组合计数，用engine.set_self_switch("A",true)切换进度。需要延迟时下一条插入普通「等待」，不要在Lua中循环等待。复制scripts/event_command.lua的正文，应用后保存/F5；检查语法错误定位、撤销、最远T/R后继续。完整API与未接入的领域见 [脚本扩展](../../docs/SCRIPT_EXTENSIONS.md)。
