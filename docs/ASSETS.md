# 资源目录与引用
打开「资源管理」。导入时检查格式和预算，生成稳定 ID（@ 加 16 位十六进制），记录路径、名称、标签、来源、大小和图片尺寸／音频时长。目录最多 4096 项，保存在 assets.echo；ID 删除后不复用。

搜索同时查名称、路径和标签；可限定目录前缀及类型。图片显示保持比例的缩略图，PNG/BMP/JPEG/GIF/RGBA 解码上限 64 MiB；音频 WAV/OGG 当前仍完整解码，长音乐流式播放待建设。

选择一个资源可改显示名称；多选资源应用标签或批量删除。移动／改名先保存工程，再一起修改物理文件和引用。稳定 ID 保持不变；旧路径引用迁移为 ID。当前引用反查覆盖工程设置、地图图层／头像、事件头像、对象模板和动画精灵表；脚本内部字符串和后续 UI／预设依赖图仍待补。

使用位置非空时阻止删除。缺失资源可「替换／重新关联」选择同类型文件，保留 ID；无效格式不会覆盖原资源。已有文件可扫描加入目录，扫描失败不提交部分目录。导入同名外部文件不直接覆盖，请使用替换入口。

资源变动和工程元数据使用回滚日志事务。打开项目会恢复未完成保存；.echo 的草稿、日志和暂存文件不进入公开或加密发布包。批量导入、字体预览、缩略图持久缓存和缓存清理策略仍待补。
