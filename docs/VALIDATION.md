# 验证与交付记录

验证日期：2026-10-15。此交付是 Echo Engine 0.4 Windows 开发预览版；功能边界见 [ENGINE_SCOPE.md](ENGINE_SCOPE.md)。

## 构建与环境

- Windows x64，GCC 13.1.0、C++20、CMake / Ninja；仅 GCC。
- Release 和 Debug 使用独立构建目录，CTest 的运行时参数指向各自的 exe，避免测试到另一配置。
- Intel Core i5-10400F；NVIDIA GeForce GTX 1060 6GB，OpenGL 4.6.0，驱动字符串 NVIDIA 560.94。
- 主程序静态链接 GCC 运行库，导入 DLL 为 Windows 系统库。Lua、Monocypher、stb_vorbis 源码固定在 third_party，发布带 THIRD_PARTY_NOTICES.txt。
- 源码使用 -Wall -Wextra -Wpedantic；最终 GCC 构建日志无 warning/error。

重现：

```powershell
cmake --preset gcc-release
cmake --build --preset gcc-release
ctest --preset gcc-release --output-on-failure

cmake --preset gcc-debug
cmake --build --preset gcc-debug
ctest --preset gcc-debug --output-on-failure

./out/build/gcc-release/echo_simulation_tests.exe --benchmark
```
