# 状态、表现与资源边界

WorldState 保存所有可变玩法：玩家/Boss/弹幕/机关、地图、动画、对话、脚本程序指针、随机种子、音频逻辑、时间控制器及配置。固定数组/计数使快照可独立恢复。

地图模板、纹理、解码PCM、Lua函数定义是不可变资源。修改它们在编辑/加载边界提交并重置试玩历史，不能携带旧历史静默更换资源定义。摄像机、GPU目标/流体、撤销栈和音频设备队列只负责表现/编辑，设备位置不反馈玩法。

正向顺序：输入→固定60Hz外步（120Hz用两子步）→事件执行→控制请求/物理按键边沿→获准的脚本输入钩子→低速许可/边沿状态→平台物理→通用对象→Boss→逐帧动画/攻击→弹幕程序→可视发射器/波次→相对线段与地形首次接触检测→对话/传送→音频逻辑→完整记录。30Hz隔步记录，120Hz每真实子步记录；对话冻结动作但仍按记录频率推进文字和音频。Hit冻结世界，禁用回溯时明确等待重开。

T以目标世界秒数定位历史并全量restore。30Hz显示插值在visual副本，用固定哈希匹配稳定子弹ID，不写回模拟。

R在控制器锁定A/B和时间端点。每次全量restore后显式重应用活动控制器，再单独计算玩家的新直线坐标。其余世界仍来自过去。快速回溯依次恢复每个经过的历史帧，防止5倍游标漏掉短命弹幕。新直线上的角色按自定义受击区域与弹幕相对扫掠，默认只在查询中扩大弹幕hitR加2逻辑像素；正常伤害半径及px/py不改。连续检测独立于普通Overlap设置，危险边界也截停；无伤弹忽略，琥珀仍按实体制动。与Boss扫掠和固体/琥珀制动一起取最早接触；结束时按新落点重新求地面/平台附着和土狼时间，保留历史跳跃标记；截断未来、增加generation、保留历史弹幕、加入落点保护并替换当前槽。T不重新求接触。

逻辑坐标float，pixelsPerUnit=0.25；摄像机连续死区/指数平滑，回溯和跨地图瞬时跟随。渲染提交才floor，默认整数最近邻放大；摄像机Smooth仅最终显示亚像素混合。三种贴图过滤、六种放大及FXAA/SSAA在GPU表现层执行，不改写世界。SSAA提高场景FBO分辨率后有界降采样。

玩家HurtConfig/FocusConfig与启用状态、按键边沿/切换锁存在WorldState。圆/凸形相对扫掠和接触/近战使用统一受击查询；地形阻挡保持实体body。绘制上限/VSync属于项目表现配置。FrameGate与Win32高分辨率计时等待分别控制绘制机会和主循环；低于60 FPS仍以至少60Hz目标处理输入、音频和固定模拟。等待处理窗口消息，无限制去除软件等待；切换帧率不重置历史。

八类碰撞矩阵位于WorldState.collisions，双侧掩码与既有固体/对象mask/阵营过滤共同控制现有交互。事件区域的上一采样玩家/区域矩形、接触、待触发、移动碰撞模式和阻挡标记进入WorldState.events；相对扫掠捕获快速穿越，前台忙碌最多保留一个信号。换页保留物理接触采样并取消旧请求，消除释放其前台和对话。阻挡路线每轴扫掠并继续消耗时间，不推人或处理挤压。

固定容量满池时弹幕按作品配置拒绝新弹/回收最旧/回收同组最旧，声部拒绝并计数；解析拒绝超限数据。Lua绑定当前世界，不捕获过去快照指针；DSL变成固定C++指令，程序指针/等待/方向入快照。Lua自持跨帧状态需序列化钩子全量同步。

project.echo为相对UTF-8路径；地图兼容ECHO_LEVEL_1..9。地图事件定义在 .echo.events，全局在 events/common.echo，试玩期间不可变。执行PC/等待/调用代次/全局数据/独立开关/调度进入WorldState，定义不复制到每帧快照。读取拒绝绝对路径、..、空字符、冒号及越出项目；导出拒绝符号链接/已有目标。整图在加载边界预载，跨地图只查纹理。

公开发布exe+game/；加密发布exe+XChaCha20-Poly1305负载+footer。先验证长度/认证再建立资源表，每次新key/nonce、元数据参与认证。离线程序必有解密能力，不是不可逆向DRM。

命名数据库 database.echo 保存不可变名称/备注/初始值；运行值仍在 WorldState.events。调试器写值先截断未来并提交完整快照；30Hz捕获之间的模拟步新增快照，已有时刻替换。历史定位全量restore、执行Lua同步、递增generation并分支；单步使用原固定模拟入口。

History的清空原因、容量/窗口淘汰及分支计数是诊断日志，不影响玩法，也不被回溯恢复。字段比对递归遍历所有命名成员和固定槽位，忽略C++填充字节、按位比较浮点；生成描述与Text/FixedList专用遍历以结构化绑定检查成员数量。只读A/B副本与512条固定报告属于编辑缓存，扫描不分配，不调用脚本钩子，也不在每个模拟帧运行。

恢复包 ECHO_RECOVERY_1 允许五项项目/当前地图/本图事件/公共事件/命名数据库元数据，加可选 objects.echo、assets.echo、animations.echo、barrage.echo，单份≤32 MiB。编辑资源overlay绑定项目根目录，载入恢复只覆盖资源读视图；运行重新构建不可变定义并重置试玩历史。保存事务提交全部工程地图与元数据后清除overlay，未保存overlay拒绝导出。整个.echo目录排除发布，恢复不承担玩家存档或外部资产备份。

单文件保存使用同目录临时文件+MoveFileEx替换/写穿。多文件保存通过 .echo/save-transaction.echo 回滚日志及排他锁，先验证整个计划，再移动资源并提交元数据；清除日志才算提交完成。异常或下次启动倒序恢复资源链并还原元数据。事务文本预算 64 MiB、128 文件、4096 移动；发布目录仍未事务化。WorldState内存布局不作为稳定存档格式。

objects.echo、animations.echo、barrage.echo 和 assets.echo 是试玩期间不可变定义。对象池 256 槽、代次引用、独立覆盖及非活动地图实例进 WorldState。动画播放进度、帧入口标记、局部判定框、攻击代次和 1024 命中收据均进快照；短帧跨越不能跳过玩法触发，收据满时先拒绝伤害并计数。命中收据使用固定哈希表，清理时构建有界临时索引。

资源引用 @ 加 16 位十六进制 ID，与实际路径分离；旧路径移动时反查工程/地图/事件/模板/动画并迁移。浏览器导入验证格式与解码预算，扫描在副本完成后提交。动画纹理在编辑边界预载，独立预算 64 MiB；游戏循环不做解码或 GL 资源加载。

输入许可由快照真理派生：事件Runner保存controlActive/controlAllowed/caller；ControlInputState保存physicalHeld/heldBlocked。resolveControl只读且有界，多个事件取许可交集，内置Hit/回溯有优先规则；不另存渲染层控制器。公共调用链按caller取消，离图保留独立公共任务。E互动许可与对话确认许可分开，创建对话时保存物理E状态，避免长按被当作新确认。时钟及限制见 [PLAYER_CONTROL.md](PLAYER_CONTROL.md)。

弹幕瞄准按发射器查询玩家/Boss/稳定部署对象/最近阵营对象/坐标。每模拟步本地缓存一次纯查询，最多64×256槽；缓存不跨帧，所有跨帧锁定/目标ID/句柄代次/缺失等待进入BarrageRuntime。预警锁定不追踪失效句柄；临发丢失重新完整预警。Barrage v2保存目标定义并兼容v1。对象阵营过滤目前只用于目标选择，通用对象受弹伤害与分阶段碰撞回调尚未完成。参考见 [弹幕制作](BARRAGE.md)。

编辑器地图、地图/公共事件和BarrageLibrary由LevelEditor统一持有并深拷贝进作者撤销。每栈64项/64MiB，估算包含预留状态存储与定义动态数组；删除/撤销不回退nextId。一条拖动在第一次实际变更时开始，松键/捕获中断时结束。编辑原点换算由barrageEditorOrigin共享给工具和渲染标记，仅用于编辑表现；正式运行仍从WorldState对象查询。作者撤销只允许编辑模式，F5才复制定义至Simulation并重开历史；当前不支持跨图作者撤销。

## 事件Lua高级入口

EventOp::Script使用原有text字段保存≤1023字节正文，事件格式v7读取旧1–6。ScriptRuntime在控制边界编译全部地图/公共事件并缓存固定索引；准备失败不换缓存，运行不用源码解析。只读能力环境提供原生API和数值代理，不能把事件闭包/可变全局作为跨帧真理；重设_ENV，持久值用WorldState。

每条执行前用预分配WorldState副本备份，失败全量恢复后由事件调度器取消所属任务/子任务、释放许可/对话并标记EventRunner.scriptFault。该锁存必须快照；换页/重开/故障前历史可恢复，公共调用者不永久等待。控制/独立开关API从当前执行上下文派生，不新增隐藏所有者。传送请求写入EventState，经Simulation原转场提交。显示最近错误为诊断信息，真实故障以runner为准。

每模拟子步重设累计100000条VM指令/32次调用预算，避免多个并行脚本各自100000条累加拖垮模拟；超限同运行错误停止请求者。预算是不可跨帧保留的派生执行上限，快照记录最终故障结果。Lua堆8MiB包含项目、缓存和临时值；索引9×33×4×32个8字节项（Lua引用/条件种类）与一份WorldState备份在控制边界分配。Lua自身分配/GC仍有成本，完整脚本性能矩阵待建。


循环使用每EventRunner固定8槽EventLoopFrame（begin/end/remaining）和loopDepth，全部进快照；0次数表示持续。端点从不可变定义最多32条扫描得到，不另设跨帧缓存。每条Loop/EndLoop/BreakLoop计入原预算，达到单任务上限或全局上限自动让出；统计进入EventState.budgetYields。结束/取消清空已用槽，防止未来计数留在分支状态。条件与循环采用严格嵌套验证，旧格式v1–5拒绝新增循环操作码。编辑命令在副本验证后提交，避免孤立Break破坏草稿。


IfScript是不可变定义的只读条件代码，运行PC/故障沿用快照Runner；不新增WorldState字段。独立_ENV只提供原生getter，属性代理在条件执行期间禁止写入，随机/传送/音频/生成API不暴露；Lua预编译引用附条件种类，禁止错误种类调用。每次条件执行完整值备份，以字节比对检测未来getter回归，返回严格单布尔后全量恢复；故障也全量回滚。临时只读标志/剩余预算均在调用结束/子步边界重设，不成为跨帧玩法真理。条件与执行脚本共享32次/100000VM预算和8MiB堆。缓存正常编译前提交，失败保留旧定义与历史。

对话正文/条目/页码/显示进度/确认边沿仍全部由WorldState保存。表现层把头像与文字栅格化为有界GDI位图，仅在整数显示进度、正文、尺寸或提示键变化时上传纹理，并在同一次OpenGL SwapBuffers前合成；隐藏布局HWND不再覆盖画布或夺取键盘焦点。物理键位是作品定义配置，采样器生成Input动作，确认和回溯不得共享按键；动作许可与按住边沿仍进快照。项目加载兼容没有keyboard_bindings的旧项目，默认E继续/R快速/T轨迹，保存及打包保持映射。

快速回溯近弹开关与扩大量在WorldState.rewind并进入全量快照；Lua代理和工程表单修改同一配置。每个子段使用32 KiB固定样本，按稳定弹ID排序与二分匹配，复杂度O(N log N)，包含恶意哈希碰撞ID也没有逐弹平方匹配或堆分配。样本只由本子段的旧世界推导，不作为跨帧状态；停止点/游标/锁存/配置都在WorldState并替换截断槽。
