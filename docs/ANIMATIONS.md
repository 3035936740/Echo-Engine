# 精灵与逐帧动画
打开「精灵与动画」，新建后选择精灵表，设置单帧宽高，再按列／行起点、帧数和帧率切分。帧索引从 0 开始；沿行扫描，到图集边缘换行。动画最多 128 帧，工程最多 256 动画、8192 总帧。

可逐帧插入、删除、排序和调整时长（1/240 到 60 秒），循环、跟随朝向及锚点独立配置。图片框和锚点使用图片像素；倍率为逻辑 px／图片 px。锚点只改变绘制位置，不改变物理坐标。越出图集的帧在应用前拒绝。

蓝框为碰撞，金框为受击，红框为攻击。框的 X／Y／宽／高使用逻辑像素，相对对象原点；朝向翻转时框随身体宽度镜像。未启用碰撞／受击框时使用对象默认身体／受击点。当前通过表单设置，直接拖动框待建设。

进入某帧可播放配置的 SE、修改命名变量，并在启用攻击框时造成伤害。连续启用攻击框视为一次攻击，关闭后再次开启或循环会开始新攻击；一次攻击对同一目标只生效一次。命中收据容量 1024，满时拒绝无法记录的伤害并计数。

右下选择玩家、Boss 或对象模板及其状态，把所选动画绑定到该状态。普通状态自动播放，不需要 Lua。受伤／死亡等完整状态联动及事件表单播放指令仍待补。复杂脚本可用 engine.play_animation(slot, generation, animationId)，0 取消手动请求。

「播放／停止」和翻转预览完全隔离，不触发变量、SE 或伤害。应用后 Ctrl+S 保存，F5 从新时间线试玩。definitions 保存在 animations.echo，运行中的 clip/frame/elapsed/loops、入口触发进度、局部判定框、攻击代次／收据全部进快照。回溯到攻击生效前再前进，会按新分支正常执行，不会使用未来标记。

动画纹理在加载／编辑边界预载，独立 GPU 预算 64 MiB。游戏帧不进行图片解码或纹理创建。摄像机投影后的最终绘制仍做像素吸附，所有玩法坐标保持浮点。
