# 受击判定、低速移动与画面采样

入口：编辑器顶部「判定 / 低速 / 采样」。普通制作使用表单；设置保存在作品的 project.echo，导出的公开/加密作品均读取同一配置。新增功能默认关闭低速，默认最近邻贴图与整数最近邻放大、关闭 AA，旧项目可直接打开。

## 受击范围与地形体积

地形体积负责站地、撞墙、单向平台；受击区域负责弹幕、敌人接触和近战攻击。修改受击点不会让角色穿墙。拾取/互动区域仍按各自规则工作。

范围来源有三种：

- **动画优先**：使用当前动画帧的受击框，没有受击框时使用自定义区域 1。是旧项目的默认值。
- **整个角色**：使用角色逻辑宽高的完整矩形。
- **自定义区域**：最多 8 个区域，任意符合伤害类别的启用区域命中即受击。可做上下双判定、身体与盾牌等组合。

每区域可设置启用、仅低速时启用、弹幕/接触/近战类别，锚点比例、逻辑像素偏移、朝向镜像、旋转、半径/宽高和凸多边形顶点。圆半径 0.01–512、宽高 0.02–1024、偏移 ±4096。多边形 3–16 点，必须按边界顺序构成凸形；拒绝凹形、星形、自交和退化边。凹形可拆成多个区域。

圆形、矩形、椭圆、胶囊、凸多边形均有表单。椭圆使用内接 32 边近似；胶囊与方形弹幕/矩形近战的组合也使用 32 边外轮廓近似。近似边界可能有细小差别，预览显示使用的轮廓；不把近似算法称为精确曲线碰撞。

| 受击形状 | 圆形弹幕 | 方形弹幕 |
|---|---|---|
| 圆 | 圆心距离与半径和，精确扫掠 | 圆与方形的圆角边界，精确扫掠 |
| 矩形/凸多边形 | 边与端点构成的圆角扩张，精确扫掠 | Minkowski 扩张凸包，精确扫掠 |
| 胶囊 | 线段加端圆，精确扫掠 | 32 边轮廓近似 |
| 椭圆 | 32 边轮廓近似 | 32 边轮廓近似 |

“相切也命中”控制边界接触是否受击。弹幕可按圆形或半边长 hitR 的方形进行判定。**连续扫掠**检测双方相对运动，默认开启；**当前帧重合**只检查终点，快速弹幕可能穿过，这是作者主动选择的行为。动画变帧后的当前形状用于该步，前后中心参与相对运动；这里没有一般旋转体的连续旋转扫掠。

近战、接触使用伤害矩形与受击区域的重合查询；它们的完整移动攻击 CCD 属于战斗系统后续建设，不因弹幕 CCD 已有就算完成。

## 显示与预览

可选择不显示、一直显示、低速时显示、按指定键显示、有弹幕或受击时显示。样式有轮廓、十字、填充、轮廓加十字；颜色、透明度、线宽、显示放大可调。**显示放大只改变提示大小，区域半径/宽高才改变命中**。

预览淡蓝矩形表示地形体积，黄色轮廓表示受击范围。点击预览定位当前区域中心；凸形顶点用坐标表编辑。先「应用当前区域到草稿」，再「应用全部配置」。五个预设包括经典小圆点、全身矩形、双圆、胶囊和凸三角形。

## 低速

默认 Shift，键号可自定义。倍率作用于水平移动目标速度，保留跳跃和重力；与 ↓ 的下穿平台分开。即时限速会把原有高速水平速度限制到低速上限；关闭即时限速则按原有加速度逐步减速。

支持按住、按一下切换、条件满足自动开启。条件可选正常行动、场上有弹幕、Boss 存活、指定开关为真；还可叠加限定地图/开关、地面/空中许可。条件暂不满足会暂停切换模式的效果；剧情锁定/对话或关闭功能会取消切换锁存。切换到其他地图只在满足该图限制时生效。

配置、启用状态、切换锁存、上一按键状态以及显示键状态全部在 WorldState。R 的路径仍是锁定的 A→B，低速不改变回溯倍率或直线路径；T 仍读取历史位置。更改编辑定义会重启试玩历史，避免旧时间线引用新配置。

高级脚本示例：

```lua
engine.configure_focus {
  enabled=true, mode="toggle", when="bullets",
  speed_ratio=0.3, key=16, ground=true, air=true, instant=true
}
engine.configure_hurt {
  source="custom", method="swept", touching=true,
  projectile_box=false, show="focus"
}
engine.set_hurt_region(1, {
  shape="circle", radius=2, anchor_x=0.5, anchor_y=0.67, mask=1
})
engine.set_hurt_region(2, {
  shape="polygon", anchor_x=0.5, anchor_y=0.5, focus_only=true,
  vertices={{0,-6},{6,6},{-6,6}}, mask=6
})
```

mask：弹幕=1、接触=2、近战=4，按位相加。区域按 1–8 顺序添加；开关和地图 Lua 编号从 1 起，0 表示不限制。脚本改动经过相同验证，进入当前世界快照。

## 贴图、放大与 AA

这三个设置独立。贴图可选最近邻、双线性、三点三角插值；图集过滤限制在当前单元内，避免读到相邻帧。放大可选整数最近邻、双线性、锐利双线性、Catmull–Rom 双三次、Lanczos 2、Lanczos 3。后两类为有界卷积滤波，可能出现振铃；锐利双线性另有强度设置。

AA 可选关闭、FXAA 快速、FXAA 质量、SSAA 2×2、SSAA 4×4。FXAA 是画布合成后的边缘处理；SSAA 实际将场景渲染到 640×360 或 1280×720，再按 4/16 个样本平均回 320×180，最后按所选方法放大。SSAA 增加场景绘制成本，最多 16 倍场景像素，不能当作性能免费的选项。纹理/画布缓冲在配置控制边界创建，不在每个模拟步扩容。

默认像素模式保持 320×180、整数倍最近邻、提交绘制前的坐标吸附。开启平滑/AA 是作者对视觉风格的显式选择，仍不修改 WorldState 的物理坐标。摄像机 crisp/smooth 是另一项视觉设置。暂不提供 MSAA/TAA/FSR/DLSS；没有用菜单名称冒充这些实现。

测试覆盖五形状、相切/严格边界、扫掠/离散、多个区域与类别过滤、朝向、低速许可/切换/即时限速、序列化与 Lua，以及 30/60/120Hz 的最远 T/R 后继续。原生验证覆盖浅/深主题、表单保存、试玩和 3×6×5 组采样/AA 的 GPU 路径。

## 绘制帧率与垂直同步

工具栏「帧率与同步」提供 30、60、90、120、144 FPS、无限制及自定义整数 1–1000 FPS；垂直同步独立开关。应用即时生效，Ctrl+S 保存到作品，导出的运行时使用相同配置。修改帧率不会重启试玩、清空历史或改写 WorldState。

```ini
frame_limit=144
vsync=0
```

frame_limit=0 表示无限制。默认 60 FPS、垂直同步开启。同步仍受显示器刷新率和驱动策略约束；上限是软件绘制目标，不保证硬件达到它。

物理固定 60 Hz，历史另按 30/60/120 Hz 采样。低于 60 FPS 时，主循环仍至少以 60 Hz 目标处理输入、音频和模拟，只跳过多余绘制；例如自定义 1 FPS 不会每秒一次批量处理操作。更高帧率增加绘制机会，不增加游戏速度。计时等待会处理窗口消息；无限制移除软件等待。失焦/最小化继续采用暂停规则。

测试比较 1/30/60/90/120/144/75/1000 FPS 下六秒的 360 个固定模拟步，全部 WorldState 字段一致；原生窗口测试逐一应用七个选项并验证保存。90 组过滤/放大/AA 的实际 GPU 绘制还验证世界状态保持不变。
