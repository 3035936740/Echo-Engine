# 已实现功能与后续设计

目标是普通平台动作与弹幕制作使用预设/表单，复杂行为才写 Lua。下面明确区分运行实现与未来设计。用户20项能力和8个制作目标的逐项核对见 [REQUIREMENTS.md](REQUIREMENTS.md)；基础子功能已实现不代表整个产品系统完成。

- 斜坡步进/滑落、实体侧推/箱体叠放、多节点平台与复杂边界。梯子/水域/传送带/落下平台/弹簧/升降、可选墙跳冲刺、玩家与普通对象乘客挤压已接入。
- 对象组件组合、特殊角色完整生命周期、动画受伤/死亡联动及判定框直接拖动；基础模板和逐帧编辑器已经运行。
- 出生点穿墙、无效传送、不可达区域、循环触发和预算超限诊断。
- 凹形碰撞加载时分解为凸形，避免运行时三角化。

### 事件与剧情
- 指令收藏/链内正文查找、跨工程复制依赖迁移、条件编辑增强、姓名/文本输入、可视天气/镜头/动画/机关命令。
- 事件断点与逐指令调试；通用角色完整生命周期、装备/道具效果、多目标任务/奖励事务。开关/变量/物品数量/单目标任务数据库及模拟帧单步、事件状态查看已有。
- 有限的非活动地图持久状态、完整实体引用/任务取消、版本化存档迁移、检查点。
- 标题/暂停/死亡/结局菜单，字体/本地化、无障碍和文本溢出检查。
- 多音乐交叉淡化、流式长音乐、声音优先级及声部抢占。

### 渲染与易用性
- 每地图天气参数、昼夜时间轴、室内遮雨、落地雨滴/积雪、雷声同步；影响玩法的天气必须进快照。
- 可选遮光/阴影，shader参数表单、GPU预算、显卡能力降级。
- 手柄/重绑定、全屏/无边框/玩家设置菜单、减少闪烁、声音分类、安全显示边距。
- 面板停靠、资源批量导入/完整依赖图、最近项目、恢复代次选择、中文错误定位。当前恢复仅覆盖编辑数据，不备份外部资产。
- 热重载在控制边界提交，地图切换不做解码/磁盘I/O。

### 性能与发布
- CPU分项/99%帧延迟/GPU完成时间、池溢出、脚本指令数、历史和进程峰值。
- 更复杂场景静态碰撞分块索引，测量后再使用SoA和任务分组。
- 关键帧+差量可作另一历史后端，但完整恢复语义不变；当前使用完整快照。
- 导出目录事务、依赖扫描、可重复构建、崩溃日志、安装/便携包和签名。
- 离线加密防直接浏览并认证篡改，无法承诺不可逆向，不堆叠自制密码。
- 每个新系统均做“退到最远→松开→继续”，包括跨地图、动画、音频、对话与Lua。

尚未建立多CPU/GPU、DPI、音频设备及长时间运行兼容矩阵。完整游戏剧情、题型、平衡、美术不能用引擎功能测试代替。
