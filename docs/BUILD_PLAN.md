# Echo Engine 产品建设清单

用户要求与此前建设性建议统一纳入本清单。目标是Windows/GCC/C++20横版动作与弹幕制作工具，常用流程预设与表单即可完成，Lua用于复杂行为。此清单不是已完成功能声明；实际范围见 ENGINE_SCOPE.md、测试见 VALIDATION.md。

用户20项完整能力及8个制作目标已逐条保留在 [REQUIREMENTS.md](REQUIREMENTS.md)，对应R01–R20与W01–W08。该文件分别记录当前基础、待建细节、后续状态规则和验收；下面的合并清单不替代逐项范围。R16回溯诊断的现有范围已通过验收；其余19个大项仍需按各自缺口建设。

## 统一架构约束

- 每项同时提供常用表单与明确的高级脚本入口；API/时机/参数/取消/持久状态/错误/预算按S01验收，未接入项不得仅凭支持Lua标为完成。
- 新系统先定义可变玩法字段，再写行为；动画标记、随机、对象生命周期、事件/菜单控制权、任务、存档相关数据都必须可快照。
- 纯GPU/摄像机/编辑会话可以不进玩法快照；任何视觉结果参与碰撞或下一帧逻辑就必须成为世界数据。
- R仍是锁定端点的新直线，世界恢复旧时间；T仍读历史轨迹，不能因新工具改变语义。
- 资源、CPU、GPU、脚本、实体池、回溯、编辑撤销与恢复均有预算；显示请求和实际容量。
- 每个系统验收都包含「退到有效窗口最远→松开/分支→继续」，并检查T/R、不同记录Hz与回溯禁用分支。
- 离线exe包含解密能力。认证加密用于资源封装和篡改检测，不承诺无法逆向；不叠加自制密码算法。
- 炸弹/投掷物仍按用户要求暂不实现。功能先服务2D横版动作与弹幕，避免把复杂通用系统强加给新用户。
